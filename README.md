# Features

- Direct movie and TV show playback from IMDb
- Beautiful fullscreen overlay player
- One-click streaming experience
- Ctrl/Cmd + Click support for opening in new tab
- ESC key support to close overlay
- Loading spinner with smooth animations
- Lightweight and fast
- Clean modern UI inspired by IMDb
- No account required
- No background tracking

# Installation

## Method 1 — Download ZIP

1. Open the repository on GitHub

2. Click: **Code → Download ZIP**

3. Extract the ZIP file

4. Open Chrome and go to: **chrome://extensions**

5. Enable: **Developer mode**

6. Click: **Load unpacked**

7. Select the extracted **IMDbPlay** folder

8. Done. The extension is now installed.

# How To Use

## Overlay Mode

- Open any IMDb title page
- Click the yellow play button
- Movie opens instantly inside a fullscreen overlay

## New Tab Mode

Use: **Ctrl + Click**

or on Mac: **Cmd + Click**

to open the player in a separate tab.

## Close Overlay

You can close the player by:

- Pressing **ESC**
- Clicking outside the video player
- Clicking the close button

# Updating

1. Download the latest ZIP from GitHub

2. Extract and replace the old extension folder

3. Open: chrome://extensions

4. Click the reload icon on IMDbPlay
